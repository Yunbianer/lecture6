# flutter_practice6

第 6 课《基础组件与布局系统》实践工程，包含课堂案例复现与自主实践两部分。

## 页面结构

| 页面 | 文件 | 对应任务 |
| --- | --- | --- |
| 案例一：个人名片 | `lib/pages/case1_profile_card.dart` | 课堂案例复现 profile_card |
| 案例二：六种对齐 | `lib/pages/case2_alignment_scenarios.dart` | 6.2-1 对齐任务卡 |
| 案例三：弹性分配 | `lib/pages/case3_flex_experiment.dart` | 6.2-2 三栏 2:1:1 与超长内容表现 |
| 案例四：层叠角标 | `lib/pages/case4_stack_badge.dart` | 6.2-3 头像徽标与图片浮层文字 |
| 案例五：容器美化 | `lib/pages/case5_container_beautify.dart` | 6.2-4 卡片装饰与剪裁 |
| 案例六：约束实验 | `lib/pages/case6_constraint_lab.dart` | 6.3 独立研究（选做） |

## 运行

```bash
flutter pub get
flutter run -d chrome
```

启动后通过底部导航切换六个页面。
